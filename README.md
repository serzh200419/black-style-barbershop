# Black Style Barbershop

Run `python -m http.server 8765 --bind 127.0.0.1 --directory dist` and open
http://127.0.0.1:8765/ to review the two-page demo locally.

Edit prices and add supplied gallery photos in `dist/content.js`. Put gallery
images under `dist/assets/` and provide Armenian, English, and Russian alt text.
